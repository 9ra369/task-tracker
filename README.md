# task_tracker

Electron製の汎用タスク管理ツール。社内の `shot_tracker`（ショット進行管理ツール）のカンバンUIを踏襲しつつ、タブ（ステータス列）をユーザーが自由に追加・編集できるように一般化したもの。

## 起動方法

初回はダブルクリックで OK（`app/` の依存パッケージが無ければ自動で `npm install` してから起動する）。

```bash
start.bat
```

手動で起動する場合:

```bash
cd app
npm install   # 初回のみ
npm start
```

Node.js（npm 同梱）が必要。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `app/` | Electron アプリ本体（`main.js` = メインプロセス、`preload.js` = レンダラーへの橋渡し、`renderer/` = 画面） |
| `data/` | 実データの保存先。`board.json` と自動バックアップ（`.bak1`〜`.bak3`）が入る。個人のタスク内容なので Git 管理対象外（`.gitignore` 参照） |
| `docs/spec.md` | 仕様書 |
| `prototype/index.html` | ブラウザで動く検証用 UI（`localStorage` 保存、実ファイル書き込みなし）。挙動確認用に残してある |

## 主な機能

- タブ（未着手/進行中/最終確認/完了、未着手と完了は固定）の追加・削除・並び替え、上端の枠線カラー
- カードの作成・編集・複製・優先度・開始日/目標日・タグ・リンク（相対パス対応）・タブ内グループ（折りたたみ可）
- Markdown 対応メモ（チェックリスト進捗をカード面に表示）
- 検索・フィルタ、手動並び替え、複数選択・一括操作（ステータス/優先度/グループ/担当者/目標日/タグ）
- Setting メニュー（機能のON/OFF・テーマ・表示名・保存先）、Edit メニュー（Undo/Redo）、キーボードショートカット
- 500ms デバウンスの自動保存、アトミック書き込み、時間軸で分散した3世代バックアップ
- JSON のエクスポート/インポート（インポート時は検証・自動修復・事前バックアップ）

詳細仕様は [docs/spec.md](docs/spec.md) を参照。
