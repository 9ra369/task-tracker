# task_tracker

Electron製の汎用タスク管理ツール（開発中）。社内の `shot_tracker`（ショット進行管理ツール）のカンバンUIを踏襲しつつ、タブ（ステータス列）をユーザーが自由に追加・編集できるように一般化したもの。

## 現状

まだ実装前の設計段階。仕様書と、ブラウザで動くUIプロトタイプ（Vanilla JS + localStorage）のみ存在する。

- [docs/spec.md](docs/spec.md) — 仕様書
- [prototype/index.html](prototype/index.html) — UIプロトタイプ。ブラウザで直接開いて操作できる

## プロトタイプの主な機能

- タブ（未着手/進行中/最終確認/完了、未着手と完了は固定）の追加・削除・並び替え
- カードの作成・編集・優先度・開始日/目標日・タグ・リンク・タブ内グループ
- 検索・フィルタ、手動並び替え、複数選択・一括操作
- Setting メニュー（機能のON/OFF・テーマ・表示名・保存先）、Edit メニュー（Undo/Redo）
- ライト/ダークテーマ、タブごとの枠線カラー
